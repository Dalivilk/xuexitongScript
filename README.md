# 学习通自动刷课脚本 V3（3.3.4）

当前版本已按用户提供的 3.3.4 油猴脚本恢复，保留自动播放、课程导航和无视频页面处理。

## 当前功能

- 默认 1 倍速，自动播放视频，播放中断时尝试恢复或静音启动。
- 视频结束后，通过目录中的实际链接进入下一小节；确认内容更新后再启动播放器，避免重播旧视频。
- 兼容 `.cells / .ncells` 和 `.posCatalog_select` 两种目录结构。
- 当前页面没有视频时，先尝试打开同小节的“视频”页签。
- 等待至少 5 秒后仍无视频、没有正在加载的文档或播放器占位时，自动进入下一节。检查间隔和页签加载可能带来额外等待。
- 切换无法确认时停止并打印日志，避免连续跳转。

**本版本没有自动选择、提交视频弹题的功能。** 遇到视频中途的任务题，需要手动选择并提交。平台要求的观看时长和任务完成标记仍由平台判断。

## 安装和更新

1. 用记事本打开根目录的 `v3_optimized.user.js`，全选复制。
2. 在篡改猴中编辑原学习通脚本，全选替换代码，保存。
3. 确认只启用这一份脚本，停用其他旧副本。
4. 回到课程播放页并刷新。篡改猴编辑器顶部的 `@version` 应为 `3.3.4`。

当前版本不需要启动额外的本地服务。

也可以复制 `v3_optimized.js`，在课程播放页的开发者工具控制台执行；页面刷新后通常需要重新执行。

当前已通过语法、源码同步、导航及无视频页面处理的模拟测试。恢复的脚本正文与用户提供版本一致，仅统一为 LF 换行；实际课程页面运行情况仍需验证。

## 已知说明

- 视频弹题需要手动处理；脚本的播放恢复机制可能使视频在弹题后方继续播放，不能把继续播放视为弹题已经完成。
- 不会自动完成阅读、章节测验等任务；平台可能因任务未完成而阻止进入下一节。
- 发生切换超时后，可手动打开目标小节，再在控制台执行 `app.run()`。
- 本地文件不会自动同步到篡改猴，更新或回退后都需要替换浏览器内安装的代码。
